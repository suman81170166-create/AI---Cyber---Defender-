# AI-Cyber-Defender 🛡️
> Built with ❤️ from Dhanasahi, Kendrapara, Odisha

An AI-powered Cyber Security system that detects and blocks hackers in real-time.

### 🚀 Features
- Detects brute-force login attacks
- Auto-blocks suspicious IPs (e.g., 45.33.22.101)
- Real-time threat alert system
- Level 1 to Level 3 protection logic

### 💻 Tech Stack
- Python 3
- Cyber Security & Threat Detection
- AI Logic

### 📂 Files
- `Block.py` - Basic hacker detection
- `Auto_block.py` - Auto blocking logic
- `Level3.py` - Advanced AI Defender
